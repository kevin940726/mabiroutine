# 台灣技術術語

本檔案列出繁體中文（台灣）技術文件的常用術語，作為撰寫與審閱時的預設用語。撰寫時直接採用這些寫法，同一概念在同一份文件中保持一致。

目標專案的術語表、產品官方名稱與使用者指示優先於本檔案。語氣、標點與排版的完整規則見 [術語與排版](terminology-and-typography.md)。
